RouteGuard is an Intelligent Route Compliance and Transport Monitoring System designed to monitor vehicle movements, track authorized routes, and identify route deviations and unauthorized stops. The system includes a web-based management portal for administrators and government officers, a mobile application for drivers, real-time GPS monitoring, trip authorization, incident management, and compliance reporting.

**Technology Stack:** React.js, React Native, Java Spring Boot, PostgreSQL, REST APIs, and Google Maps Platform.
